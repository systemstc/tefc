How This CMS Works

This is a static website CMS. It stores edits in your browser localStorage under tefcCmsSettings. The home page reads that data when it opens, so updates stay after closing and reopening the file in the same browser.

For multi-user publishing on a server, the same interface can later be connected to a database/API. For now, this gives you working local control without a backend.
